================================================================================
  HOW TO USE
================================================================================

1. START SERVER:
   npm start

   Server will display:
   - Local access URLs
   - LAN IP addresses
   - Mobile app configuration examples

2. FIND YOUR IP:
   - Shown automatically at server startup
   - Or run: npm run network
   - Or manually: ifconfig (Mac/Linux) or ipconfig (Windows)

3. UPDATE MOBILE APP:
   Edit: student_app/lib/config/api_config.dart
   
   Change:
   static const String baseUrl = 'http://10.0.2.2:3000/api';
   
   To:
   static const String baseUrl = 'http://YOUR_LAN_IP:3000/api';

4. REBUILD APP:
   cd student_app
   flutter clean
   flutter run

================================================================================
  FIREWALL SETUP
================================================================================

macOS:
  sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /usr/local/bin/node
  sudo /usr/libexec/ApplicationFirewall/socketfilterfw --unblockapp /usr/local/bin/node

Windows (Admin):
  netsh advfirewall firewall add rule name="Node.js Server" dir=in action=allow protocol=TCP localport=3000

Linux:
  sudo ufw allow 3000/tcp

================================================================================
  TROUBLESHOOTING
================================================================================

Can't connect from phone?
  1. Check both devices on same WiFi
  2. Test in phone browser: http://YOUR_LAN_IP:3000
  3. Check firewall settings
  4. Verify correct IP in app config

Multiple IPs shown?
  - Use one starting with 192.168.x.x or 10.0.x.x
  - Avoid 169.254.x.x (link-local)

Server shows no LAN IPs?
  - Ensure connected to WiFi
  - Check network adapter enabled
  - Try different WiFi network
